## [0.2.0] — 2026-11-20

### Архитектура и стабильность
- Windows: single-instance lock. Повторный запуск не открывает новое окно, а сигналит уже работающему процессу через именованное событие ShowEvent. Раньше второй запуск звал ShowWindow напрямую, это расходилось с внутренним состоянием winit и иногда ломало закрытие в трей.
- Очередь команд в аудиопотоке схлопывает быстрые клики по трекам: выполняется только последний Play, промежуточные отбрасываются.
- state.json пишется через временный файл (.json.tmp) с заменой — без повреждения плейлиста при отключении питания.
- Плейлист при старте восстанавливается в фоне. Недоступные файлы не теряются, их пути остаются в missing_playlist_paths.

### UI
- Фон рисуется процедурно (звёзды, облака, кометы) через Painter, без ассетов.
- Таблица треков сжимает колонки (compact_scale) на узких окнах.
- Разделители интерфейса — ровно 1 физический пиксель на любом DPI (round_to_pixel_center).
- Кнопки транспорта, слайдеры и иконки сайдбара отрисованы вручную через Painter.
- Pixelify Sans — первый шрифт, системные шрифты остаются fallback'ом для кириллицы.

### Производительность
- Лимит 100 МБ на сканируемые файлы — lofty/rodio зависают на больших.
- LRU-кэш обложек ограничен 200 записями.
- Не больше 4 обложек декодируется за кадр.
- state.json сохраняется только при изменении хэша (state_signature).

### Теги
- fix_tag_encoding проверяет mostly_cyrillic перед исправлением кодировки, чтобы не ломать латиницу с диакритикой (Björk).

### Сборка
- Иконки и шрифты встроены в .exe через include_bytes!, assets/ рядом не нужен.
